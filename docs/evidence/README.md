# Q5 evidence artifacts

Machine-readable proof for the Q5 alert (see `docs/specs/q5-spec.md` and
`docs/q5-alert-proof-template.md` for the narrative).

| File | What it is |
|---|---|
| `q5-alert-monitor.jsonl` | One JSON record per alert evaluation. Written by `backend/scripts/q5_alert_monitor.py`, which applies the dashboard alert's own metric, window and threshold through the Langfuse **Metrics API v2** (`totalTokens` / `totalCost` on `name = answer`, 1-hour window). Records with `"severity": "ALERT"` are the firing evidence; earlier `"OK"` records are the false-positive check. |
| `q5-trigger-burst.log` | The deliberate trigger (`backend/scripts/q5_trigger_burst.py`): 20 consecutive references answers on one paper, with per-turn token counts and a cumulative total. |

Both are regenerated by:

```bash
cd backend
python3 scripts/q5_trigger_burst.py p_9c3022cf 20 "What are the references?"   # trigger
python3 scripts/q5_alert_monitor.py --window 1                                 # evaluate
```

The monitor exits 0 when healthy and 2 when the alert fires, so it can be run
from cron and wired into any notifier by setting `ALERT_WEBHOOK_URL`.
